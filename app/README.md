# app

The frontend: React + [TanStack Start](https://tanstack.com/start) (server-side rendering, built on Vite) + TypeScript, managed with bun.

## Stack

- React 19, TanStack Start + TanStack Router (SSR, file-based routes), Vite, TypeScript
- `@solana/wallet-adapter-*` for wallet connection
- `@solana/web3.js` for RPC
- `@anchor-lang/core` as the typed client for the `course_program` program

## Current state

A smoke test only. `src/SmokeTest.tsx` connects a wallet and calls the template `initialize` and `increment` instructions, then reads the counter back. It proves the full wallet → RPC → program → read path, and should be deleted once real instructions exist.

## Environment variables

Create `app/.env.local` (git-ignored) if you need to change the defaults.

| Name | Default | Description |
|---|---|---|
| `VITE_RPC_URL` | `http://127.0.0.1:8899` | Solana RPC endpoint (localnet by default; use a devnet URL to test there). |
| `VITE_API_URL` | `http://localhost:3001` | Optional Hono support server. Keep its `CORS_ORIGIN` in sync with the app origin. |

The program ID comes from the IDL (`src/idl/course_program.json`), so it is not configured here.

## Workflow

Run on Windows from the repo root:

```bash
bun install
bun run dev:app      # http://localhost:5173
bun run build:app    # production build (client + SSR bundle) + type-check
bun run --cwd app start   # serve the production build on :3000 (PORT to change)
```

Whenever the program's interface changes:

```bash
bun run program:build   # runs in WSL
bun run sync-idl        # copies the IDL and types into src/idl/
```

Do not run `bun install` from WSL in this folder: it would install Linux-only binaries that Windows can't run.

## Layout

```
src/
├── router.tsx        router factory (TanStack Start entry)
├── routeTree.gen.ts  generated by the Vite plugin; do not edit
├── routes/
│   ├── __root.tsx    HTML shell: <head>, stylesheets, polyfill import
│   └── index.tsx     home page
├── Providers.tsx     connection + wallet providers
├── SmokeTest.tsx     temporary end-to-end check
├── lib/
│   ├── config.ts     RPC and API URLs
│   ├── polyfill.ts   Buffer polyfill for the browser
│   └── program.ts    builds the typed Anchor Program, derives PDAs
└── idl/              generated by `sync-idl`; do not edit by hand
serve.ts              production server (Bun): static assets + SSR handler
```

## Server-side rendering

Routes render on the server by default. Wallets only exist in the browser, so wallet UI (`Providers`, `WalletMultiButton`, `SmokeTest`) is wrapped in `<ClientOnly>` in `routes/index.tsx`. Keep new wallet-dependent components under that boundary, or mark the route `ssr: false`; public pages (landing, docs, read-only views of chain state) can render on the server for SEO and fast first paint.

`routeTree.gen.ts` is generated on `vite dev` / `vite build`, so run one of those before type-checking from a fresh clone.

## Notes

- **Wallet network.** Point your wallet at the same cluster as `VITE_RPC_URL`, and make sure it has SOL there.
